## O que é o Fable 5?

O Fable 5 é o modelo de linguagem mais recente da **Anthropic** — e o primeiro da nova geração "Fable". Enquanto a família Claude 4.X (Opus, Sonnet, Haiku) segue disponível e em uso massivo, o Fable 5 representa um salto de geração: novo paradigma de treinamento, maior capacidade de raciocínio longo e profundo, e desempenho superior em tarefas que exigem contexto extenso.

Em termos simples: é como passar de um analista sênior muito bom para um sócio que entende o seu negócio.

## A família completa de modelos

Antes de mergulhar no Fable 5, é importante entender o ecossistema. A Anthropic mantém quatro modelos ativos simultaneamente, cada um com um perfil de uso ideal:

| Modelo | ID na API | Perfil de uso |
|--------|-----------|---------------|
| **Fable 5** | `claude-fable-5` | Raciocínio profundo, projetos complexos, agentes autônomos |
| **Opus 4.8** | `claude-opus-4-8` | Escrita avançada, análise detalhada, tarefas longas |
| **Sonnet 4.6** | `claude-sonnet-4-6` | Equilíbrio perfeito entre velocidade e qualidade |
| **Haiku 4.5** | `claude-haiku-4-5-20251001` | Tarefas simples, alto volume, custo otimizado |

> **Regra geral:** use o Haiku quando a tarefa for repetitiva ou simples. Use o Sonnet para o dia a dia. Use o Opus ou o Fable 5 quando o trabalho realmente importa.

## O que o Fable 5 faz de diferente

### Janela de contexto expandida

O Fable 5 consegue processar documentos muito mais extensos de uma única vez — contratos longos, repositórios inteiros de código, relatórios completos. Você para de trabalhar com recortes e começa a trabalhar com o quadro completo.

### Raciocínio em cadeia mais sofisticado

Tarefas que antes exigiam várias conversas separadas agora acontecem em uma só. O modelo mantém coerência ao longo de raciocínios longos e complexos, sem "esquecer" o que foi dito no começo.

### Agentes autônomos e uso de ferramentas

O Fable 5 foi otimizado para atuar como **agente** — ou seja, executar sequências de ações usando ferramentas externas (busca na web, código, APIs) com muito menos supervisão humana. É o modelo ideal para automações sofisticadas.

### Código de altíssimo nível

Se você usa IA para programar, a diferença é imediata. O Fable 5 entende arquiteturas de sistema, refatora código com critério, identifica bugs sutis e escreve testes com uma precisão que modelos anteriores não alcançavam.

### Caminho 3: API direta (para builders)

Se você está construindo um produto ou automatizando processos internos, a API da Anthropic é o caminho.

```bash
# Instalar o SDK
npm install @anthropic-ai/sdk
```

```typescript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
});

const message = await client.messages.create({
  model: "claude-fable-5",
  max_tokens: 4096,
  messages: [
    {
      role: "user",
      content: "Analise este contrato e identifique cláusulas de risco:",
    },
  ],
});

console.log(message.content);
```

> **Dica:** A Anthropic oferece créditos gratuitos para novos accounts via API. Acesse **console.anthropic.com** para criar sua chave e acompanhar o uso em tempo real.

## Primeiros passos: um roteiro de 30 minutos

**Minutos 1–5: Criar a conta**

Acesse claude.ai e crie sua conta. A versão gratuita já permite testar o modelo com as funcionalidades principais.

**Minutos 5–15: A primeira conversa de verdade**

Não comece com "me escreva um e-mail". Comece com um problema real que você tem no trabalho agora. Cole um documento, um trecho de código, ou descreva um desafio específico. O Fable 5 performa melhor com contexto rico.

**Minutos 15–25: Iterar e refinar**

O que separa usuários medianos de usuários avançados é a capacidade de iterar. A primeira resposta raramente é a melhor. Peça ajustes, dê mais contexto, questione o raciocínio. O modelo responde muito bem a direcionamentos.

**Minutos 25–30: Definir um fluxo recorrente**

Identifique **uma tarefa** que você faz toda semana e que poderia ser acelerada com IA. Esse é o seu ponto de entrada. Depois que esse fluxo virar hábito, os outros vêm naturais.

## Dicas para extrair o máximo

**Dê contexto, sempre.** O modelo não conhece sua empresa, seu cliente, seu mercado. Quanto mais você contextualiza, melhor a resposta.

**Use role prompting.** "Você é um especialista em finanças B2B com 20 anos de experiência..." muda completamente o calibre da resposta.

**Quebre tarefas grandes.** Em vez de "escreva um plano de marketing completo", faça "primeiro me ajude a definir o ICP. Depois vamos para o posicionamento." Passo a passo.

**Peça raciocínio explícito.** "Explique o seu raciocínio antes de dar a resposta" produz respostas mais acuradas e revisáveis.

**Salve os prompts que funcionam.** Quando encontrar uma abordagem que dá resultado, documente. Prompts bons valem dinheiro.
